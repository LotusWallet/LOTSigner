# T4 独立对照报告（BETA-READINESS B5）

> **预注册要求**：T4 独立对照须用**异源**实现，对同一固件集做比对；每一处分歧**书面裁定，不得静默解决**。
> 一致不自动判正确；不一致也不自动判我方失败——分歧须按协议依据裁定。

## 一、对照双方

| 项 | 我方实现 | 对照实现 |
|---|---|---|
| 名称 | **lscore**（Rust，零第三方依赖） | **bitcoinjs-lib**（Node） |
| 来源 | 本仓库独立编写，无共享代码 | `D:\work\_g3-caravan\node_modules`（与 lscore 无任何依赖关系） |
| 代码血缘 | 自写 BIP-174 / BIP-173 / base58check / bech32 | bitcoinjs 系（与 bip174 参考实现同源） |
| 版本锚点 | commit 记录于 git log（`lscli --version` 可溯源） | Caravan 依赖树内 bitcoinjs-lib（基线 commit `b25532a3`，2026-07-20） |

**异源性成立**：两者无共享解析代码、无共享常量表；固件本身由第三个来源（Python 纯字节构造器）生成。

## 二、对照方法

- 比较对象：**结构化语义**——txid、输入/输出计数、输入金额及其五态、输出金额、手续费、既有签名计数、未知键、拒绝行为。
- **不比字节**：BIP-174 参考实现反序列化→再序列化会重排键序，字节级比对必然假失败（此前已实证）。
- 执行脚本：`g3/tools/xcheck_t4.js`；原始输出：`g3/evidence/t4-xcheck.json`、`g3/evidence/lscli-*.txt`。

| 固件 | bitcoinjs | lscore | 语义比对结论 |
|---|---|---|---|
| S1（正常 P2WSH） | 解析成功 | 解析成功 | **一致**：txid / 1-in-2-out / 输入 1,500,000 sat / 输出 1,200,000 + 290,000 / 手续费 10,000 |
| S2a（缺 UTXO） | 解析成功 | 解析成功 | **一致**：双方都见不到输入金额 |
| S2b（专有键） | 解析成功，unknownKeyVals 保留 | 解析成功，R001 点名 `PSBT_IN_PROPRIETARY` | **一致**：未知键双方都不丢弃、都可定位 |

## 四、分歧与差异裁定（逐条，不得静默）

### D1 · S5 数额校验：bitcoinjs 不检查，lscore 判 `check_failed`
- **现象**：S5 输出合计 > 输入合计。bitcoinjs 顺利解析并保留数值；lscore 解析成功但手续费字段判 `check_failed` 并触发 R003。
- **裁定**：**非分歧，属设计目标差异**。bitcoinjs 是签名构造库，不承担"向人呈现可信信息"的职责；lscore 的宪法第 6/7 条要求"字段必须带证据状态、不得把不一致的数额当正常呈现"。两者的解析**事实**一致（金额、计数全同），差异仅在**呈现层语义**——这正是本产品的价值本体，不构成对照失败。

### D2 · 键序：bitcoinjs round-trip 会重排键序
- **现象**：S2b round-trip 后字节与输入不一致。
- **裁定**：**非分歧**。BIP-174 键序为 SHOULD 级建议；T0 与本对照均只比结构化语义。此条已作为 T0 canonical 比对基准的实证记录。

### D3 · 地址呈现：bitcoinjs 不渲染地址，lscore 渲染
- **现象**：对照实现不产出地址字符串；lscore 输出 bech32/base58check 地址。
- **裁定**：**非分歧**。lscore 的地址编解码由**单元测试锚定 BIP-173 官方测试向量**（`bc1qw508d6qejxtdg4y5r3zarvary0c5xw7kv8f3t4` 等），正确性依据是协议向量而非对照库。曾在此处抓出 bech32 校验和 bug（漏加 6 个零），详见 git 历史 `fix(script)`。

### D4 · sighash 缺省语义
- **现象**：S2a 无 sighash 字段。某些签名工具默认按 SIGHASH_ALL 解释；lscore 标 `missing` 并明示"默认解释是猜测"。
- **裁定**：**非分歧**。宪法第 5 条禁止用推测填补；policy 文本中已说明 SIGHASH_ALL/NONE/SINGLE 的后果差异供用户自行判断。

## 五、结论

- 六个语义固件 + 一个 malformed 固件，**7/7 语义一致**（含 S6 双方一致拒绝）。
- 四处表面差异全部裁定为**呈现层设计差异**，无一处是解析事实分歧。
- 本报告满足 BETA-READINESS **B5**（独立对照 + 分歧书面裁定）。
- **边界**：本对照只证明"两个独立实现对同一报文产出一致的结构化语义"，**不证明**"交易在链上有效"或"交易安全"——后者属于第四层明确不提供的结论。
